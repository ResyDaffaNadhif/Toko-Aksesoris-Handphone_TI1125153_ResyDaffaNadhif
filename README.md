## Tugas Praktikum Materi Fungsi Dan Prosedur 
Nama   : Resy Daffa Nadhif 

NIM    : TI1125153

Matkul : Algoritma & Pemograman 

Program ini adalah aplikasi kasir sederhana untuk penjualan aksesoris handphone yang dibuat menggunakan bahasa pemrograman C++. Program ini menampilkan daftar produk seperti tempered glass, earphone, charger HP, dan kabel data, kemudian pengguna dapat memilih barang, menentukan jumlah pembelian, serta memasukkan uang pembayaran. Setelah itu, program akan menghitung total belanja, pajak sebesar 0,5%, dan total tagihan yang harus dibayar, serta menghitung uang kembalian. Hasil transaksi kemudian ditampilkan dalam bentuk struk pembelian yang berisi detail barang, harga, jumlah, pajak, total pembayaran, dan kembalian. Program ini juga memungkinkan pengguna untuk mengulang transaksi sehingga dapat digunakan secara berulang dalam satu sesi penggunaan.
